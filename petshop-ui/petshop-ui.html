PetShop Mini Program · UI Spec · v1.1 · 2026-09-15

宠物店小程序 UI 设计稿

同一套页面结构，三套可切换主题：标准模式（专业暖赭，全龄段通用）、喵喵主题（奶油蜜桃 + 猫系元素）、汪汪主题（天蓝明黄 + 犬系元素）。点击顶部标签切换页面，三台原型机同步预览。

范围标注：本稿页面元素全部属于一期（MVP）。二期功能（商家版小程序、顾客自助买单、同城配送、积分抵现与兑换、营销玩法如优惠券 / 生日券 / 秒杀、小票打印机、批次与保质期）不得出现在本稿页面中——「我的」页此前画出的「优惠券」计数已替换为一期实际能力「退款记录」。

信息架构的权威来源是 PRD 3.x。本稿以下几处与 PRD 当前描述不一致，属设计先行、待产品拍板的提案，未确认前开发以 PRD 为准：
① 首页形态——本稿为「问候语 + 功能大卡」，PRD 3.2 为「门店信息卡 + 服务分类宫格 + 特卖专区横滑 + 价目表入口」；
② 价目表形态——本稿为「方块瀑布流」，PRD 3.2 为「服务项目卡片流」；
③ 门店信息位置——本稿移至预约页「到店信息」与「我的」页入口，PRD 2.1 / 3.2 放在首页第一屏。
任一项被采纳，须同步回写 PRD 3.2 后再开工。

「我的」页含余额 / 次卡 / 退款记录 / 等级与宠物档案卡（疫苗 / 驱虫到期提醒、体重趋势、洗澡美容记录，点击圆点切换宠物）。价格类展示数值一律取自 ../petshop-data/pricing.json（唯一事实来源）。

设计规范对比

三套主题共享同一套组件结构与信息层级，仅通过设计令牌（色彩 / 圆角 / 装饰元素 / 文案语气）差异化，保证开发时可一套代码、配置切换。
