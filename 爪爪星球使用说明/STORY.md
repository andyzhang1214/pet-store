# STORY.md — 爪爪星球 · 小程序 + 门店后台使用说明

## 受众与目标
- 受众：门店店长/店员（怎么用）、技术/管理同事（怎么实现的）。
- 目标：翻完就知道「有哪些功能、在哪个端、流程怎么走、资金与安全怎么保证」。

## 叙事主线（是什么 → 怎么用 → 怎么保证）
1. **封面**：爪爪星球 · 宠物门店一体化系统使用说明。
2. **系统全景**：三端一体 —— 顾客小程序（4 主页面 + 6 子页）／门店后台（14 个功能页）／后端服务（7 个业务模块），同一套数据。
3. **顾客端小程序**：预约、商城、宠物档案、钱包（余额+次卡）、健康档案、订单自提码；微信 mock 登录，开发期零门槛联调。
4. **门店后台功能地图**：核销台、退款审核、订单、预约、结算、会员、商品库存、服务价目、卡与充值、会员等级、门店规则、账号、审计 —— 分「日常作业 / 配置管理 / 监督留痕」三组。
5. **核心流程（hero）**：小程序预约 → 出示核销码 → 后台扫码核销 → 到店结算（余额抵扣）→ 全程留痕。配真实截图。
6. **本期新功能：扫码核销（hero）**：三种核销方式（摄像头 / USB 扫码枪 / 手动输码）+ 出码弹层；环境不满足时优雅降级并给替代方案。
7. **余额与次卡资金设计**：担保冻结 → 到店核销扣款；本金/赠金自动拆分；每笔动账都有流水与余额快照。演示数据：充值 300+30 → 结算扣 130 → 余 200、冻结 0。
8. **安全与留痕**：首次登录强制改密、角色权限（店员/店长）、操作人由服务端解析不可伪造、配置变更全量审计。
9. **技术实现**：多模块单体（7 模块）、MyBatis-Plus + CAS 状态机防并发重复扣款、前端零依赖、115 项自动化测试全绿。
10. **快速上手**：启动命令、演示账号、注意事项（摄像头需 HTTPS、扫码枪免改造、生产关闭 mock）。

## 每页角色
- hero：P1 封面、P5 核心流程、P6 扫码核销。
- supporting：其余。
